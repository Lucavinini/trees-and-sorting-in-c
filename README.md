# trees-and-sorting-in-c

Repositório acadêmico para estudar estruturas de árvores e algoritmos de ordenação
usando a linguagem C.

## Estrutura do projeto

```text
trees/
├── arvore.c   # implementação das operações da árvore
├── arvore.h   # interface da árvore
└── main.c     # exemplo de uso
```

## Conteúdo atual

### Árvores binárias

A pasta `trees/` contém uma implementação de árvore binária com operações para:

- criar árvores e nós;
- verificar se a árvore está vazia;
- buscar valores;
- imprimir a árvore em pré-ordem;
- liberar uma árvore completa;
- remover uma subárvore.
